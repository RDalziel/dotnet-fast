# Release notes — the 0.x series

The plain-English notes for every `0.x` release used to live in this file. They predate the `1.0.0`
compatibility promise and the NuGet package (`nuget.org` publishing started at `1.0.0`), so nothing
in them is a claim about today's tool — the CLI surface itself still moved between `0.x` versions.

Nothing was deleted: the full text is in git history. `git log --follow -- docs/public/RELEASES-0.x.md`
finds every version of this file, or check out any `0.x` tag directly.

Notes for `1.0.0` and later are in [RELEASES.md](RELEASES.md).
